- Python 3.9, доп библиотеки не нужны

Запускается через python main.py, вводите адрес через input

- Выполняет 10 последовательных GET-запросов.
- Дожидается полной загрузки каждого файла.
- Измеряет время каждого запроса.
- Выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

- Время — (сек).
- Размер данных — KB и MB.
- Скорость скачивания — мегабиты


Если не удалось скачать файл или соединение прервалось по таймауту, скрипт выведет сообщение об ошибке.
